# 中东(海湾GCC)市场开发计划

更新: 2026-09-13
范围: 阿联酋 / 沙特阿拉伯 / 卡塔尔 / 科威特 / 巴林 / 阿曼(黎凡特与受冲突影响的中东国家暂不列入,性价比低)

## 为什么单独做这个市场

- 泰国TAT官方数据显示"中东"整体2026年入境下滑24.9%,但这是黎凡特/冲突国家拖累的整体数字——**沙特、阿曼、卡塔尔是逆势扩张的**。
- **沙特航空2026年新开利雅得/吉达直飞普吉**,是当前需求变化的最直接驱动力,建议沙特列为第一优先级国家。
- 海湾市场客单价高、偏好大别墅(6-10卧)、重视私密性和管家服务,和VillaGO现有房源结构天然契合。

## 阶段划分

### 第一阶段:数据与素材(现在 - 第2周)
- [x] 建立中东联系人数据库(公司+协会,19条起步,见 `middle_east/crm.csv`)
- [x] 建立双语(阿语/英语)WhatsApp三触点话术 + 正式邮件模板
- [x] IG矩阵22套别墅文案加阿语标签(被动获客层,已上线)
- [ ] 人工在VillaGO自己的IG账号(已登录状态)搜索以下阿语标签,补充5-10个真实活跃的海湾"别墅/家庭游"内容创作者账号,记录粉丝量级和联系方式:
  `#فيلا_بوكيت` `#فيلات_فاخرة` `#عائلات_بوكيت` `#رحلة_عائلية_بوكيت` `#فلل_تايلاند`
  (这一步必须登录账号才能看到完整结果,自动化工具/无登录抓取都拿不到,只能人工搜10分钟)
- [ ] 视预算决定是否联系头部网红(Mo Vlogs、Anas Marwah/Anazala Family、Taim AlFalasi等百万级账号——报价高,建议先从5-20万粉丝的中腰部账号切入)
- [ ] 确认公司层面:是否能提供清真厨房 / 阿语管家服务——确认后补一版"喊话文案"

### 第二阶段:破冰与首触(第3-6周)
- 优先顺序:沙特(直飞驱动)→ 阿联酋(存量最大)→ 卡塔尔/科威特 → 巴林/阿曼
- 执行方式:每天在VillaGO自己的IG账号上,对候选服务商的最近3-5条内容做真实互动(点赞/评论),连续2-3天后再发WhatsApp首触
- 用 `me_followup_reminder.py` 自动生成的每日清单发送WA Day1消息,发送后在CRM里把该行 `stage` 改成 `wa_day1_sent`,`last_contact_date` 填当天日期——脚本会自动算出Day3/Day7的到期提醒
- 协会渠道(ATTAC / KTTAA)优先打电话或发邮件咨询"是否可介绍会员合作机会",不走WA冷启动

### 第三阶段:转化与首单(第7-10周)
- 目标:每个已回复的服务商发送trade rate sheet + 佣金政策,争取至少1单试单
- 试单后附赠一次"真人体验官"素材包(实拍视频/照片),便于对方自己的渠道二次传播
- 记录每个服务商的实际转化路径,反哺模板迭代

### 第四阶段:规模化与展会卡位(第11周起,同步规划2027)
- 沙特Travel Market(预计2027年3月,利雅得)、ATM迪拜(预计2027年5月)提前3-6个月申请展位/买家证件
- 视第三阶段转化效果,决定是否投入付费获客(LinkedIn Sales Navigator账号、网红合作预算)

## 自动化范围说明(诚实边界)

**能自动化的**:
- 每天自动读取CRM,算出"今天该跟进谁"(Day3/Day7到期提醒),自动生成已经填好公司名的阿语+英语消息草稿
- 自动把这份清单发布成本仓库的GitHub Issue,每天更新,不用你自己记日期、不用手翻表格

**不能/不应该自动化的**(如实说明,避免误解):
- **实际发送WhatsApp/邮件**——本环境没有接入WhatsApp Business API或邮箱发送工具,而且冷启动外联属于"以你的名义对外发消息",按规则必须由你本人操作或明确授权后我才能代发
- **抓取Instagram/TikTok网红账号**——两个平台的标签搜索页面都需要登录才能看到内容,自动化脚本/无登录浏览拿不到东西,这一步只能人工在你自己已登录的账号里搜索,我已经把要搜的标签列在第一阶段里了
- **联系人邮箱/决策人挖掘到LinkedIn级别精度**——需要LinkedIn Sales Navigator账号或付费数据服务,现在的搜索引擎只能拿到公司代表邮箱/前台电话
